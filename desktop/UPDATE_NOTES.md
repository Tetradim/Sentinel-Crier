Crier 0.5.0 adds opt-in account ID banks and host-specific stock/option allocation pools to Windows, iOS and Android. Several host connections can share one Alpaca account within one receiving installation. Each trade retains an immutable numeric ID, original source identity, reserved cash/units and independent ownership. Units, dollars and destination-equity percentage pools are supported. Stocks and options compete for one shared cash balance; only option buys require separate options buying capacity. Exits cannot consume another host's units.

Windows Recovery assistant now shows broker-versus-ledger quantities and original order results, including archived IDs and late fills. Verified-flat repair requires fresh account/funds evidence, every original order resolved, no Crier holdings or pending orders, and unchanged external inventory. It retains IDs/history, records an audit event and leaves entries paused. Missing outcomes never authorize resubmission or release reservations.

Supported Windows update source: 0.4.0. Setup remains explicit, drains routes and refuses unresolved legacy orders/open legacy Crier lots. New pools start at zero. Configure pools, reconnect, inspect account/environment and explicitly enable entries. Preserve the complete profile, including account-bank.sqlite3, connections.sqlite3 and every route journal. Updates create a private recovery snapshot after workers drain. Stopping the app does not cancel broker orders. Never delete recovery evidence to bypass a block.

The iOS trading workspace adds a compact dark header, searchable positions, separated order-ticket sections, exact option-contract summaries, adaptable chart controls and read-only manual-order recovery checks. iOS distribution still requires owner-deferred Apple signing. Android's signed 0.5.0 package is provided separately. Webull/provider activation, physical-device/broker acceptance and Apple enrollment/signing are deferred by the owner; simulator tests are not substitutes for them. No Webull/Tradier executor, cross-installation shared-account coordinator, independent strategy or automatic market fallback is activated by this release.
