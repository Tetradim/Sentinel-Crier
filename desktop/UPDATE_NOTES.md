Crier 0.5.1 fixes account-bank recovery and connection routing, and simplifies the native trading workspaces.

Windows allocation dialogs stay bound to their original connection. All routes sharing a recovering account remain paused through success, failure and cancellation. Provider callbacks, including manually pasted returns, resolve to the locally pending originating flow rather than the visible account. Trading now has separate Order, Positions and Activity views with scrolling at scaled window sizes.

iOS preserves broker identity, cumulative fills, terminal progression and fill-price evidence before updating manual-order history or admitting account-bank ownership. Queued host entries require a new deliberate command after reconnect or account-bank repair. Android recovers only bank-proven non-submissions as terminal local refusals; ambiguous submissions remain blocked. Bank evidence reads run off the UI thread and pool editing explains when workers must stop.

The mobile account-first layout keeps the selected connection and PAPER/LIVE state visible, with direct trading, positions and orders navigation. Setup, alerts and recovery remain available. Disconnected screens never invent market prices or account values. Financial journals, ownership and bank transactions retain their existing durable formats.

Before installing, stop Crier workers and create a private recovery snapshot. The updater checks compatibility, hashes and the signed update catalog; installation remains explicit. Windows installer acceptance covers install/upgrade/downgrade rejection and journal preservation. The Windows installer remains Authenticode-unsigned. Android 0.5.1 is distributed separately with the existing operator signing identity.

Apple enrollment/signing, physical-device/broker acceptance and Webull/provider activation remain owner-deferred. This update does not activate a Webull executor or coordinate one brokerage account across several receiving installations. No real brokerage orders or customer notifications are part of automated acceptance.
